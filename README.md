# # Tic Tac Toe Game

## About the Project

Tic Tac Toe is a complete desktop game developed using **C#**, built on the **.NET Framework** platform with **Windows Forms**.

Through this project, I applied several C# concepts and gained practical experience working with Windows Forms controls, event handling, and building interactive graphical user interfaces.

## Game Features

- **Win Detection:** The game detects when a player wins, ends the game, and announces the winner.
- **Draw Detection:** The game detects a draw when all available cells are occupied without a winner, then ends the game.
- **Preventing Repeated Moves:** Players cannot select a cell that has already been occupied.
- **Dynamic User Interface:** The interface updates according to the current game state and players' moves.

## Highlights

- Attractive and user-friendly graphical interface.
- Smooth and interactive gameplay.
- Practical application of C# and Windows Forms concepts.

## Technologies Used

- C#
- .NET Framework
- Windows Forms
